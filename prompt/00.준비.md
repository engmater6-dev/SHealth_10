## 1. 프로젝트 개요

- 삼성 헬스 데이터로 **나이대별** 저체중/정상체중/과체중/비만 통계 계산
- 누락 체중(`weight = 0`)은 **같은 나이대 평균**으로 보정
- 입력: `id, age, weight(kg), height(cm)` — `shealth.dat`
- BMI = 체중(kg) / 키(m)²
- 분류 기준
  - 18.5 이하: 저체중
  - 18.5 초과 ~ 23 미만: 정상체중
  - 23 이상 ~ 25 미만: 과체중
  - 25 이상: 비만

### 프로젝트 구조

```
shealth.dat
src/
  main/python/
    shealth.py           - SHealth 클래스 (BMI 계산 및 통계)
    shealth_bmi.py       - main 진입점
  test/python/
    test_shealth_bmi.py  - 단위 테스트
prompt/
  00.준비.md             - 본 문서 (프롬프트 등록)
report/
  00.report.md           - 준비 단계 작업 보고서
.cursorrules             - Cursor AI 프로젝트 규칙
```

### 실행 환경

```bash
# 가상환경 (Windows)
python -m venv venv
venv\Scripts\activate
pip install pytest

# 실행
cd src/main/python
python shealth_bmi.py

# 테스트
python -m pytest src/test/python/test_shealth_bmi.py -v
```

```

```

**수행 내용**
```powershell

**현재 Git 상태 (동기화 완료 후)**

| 항목 | 값 |
|------|-----|

| 로컬 ↔ 원격 `main` | 동일 |
| 작업 트리 | clean |

**커밋 히스토리**

```

## 4. TDD·리팩토링용 참고 프롬프트

> 출처: `TDD 기반 암호 검사기 또는 BMI 프로젝트용 프롬프트.txt`

### [1] TDD 시작 — 실패하는 테스트 먼저

```
BMI 계산기 프로그램에 대해 TDD를 시작하고 싶어.
1. BMI 계산 로직에 대한 테스트
2. 평균 보정(weight=0 or height=0) 테스트
3. BMI 카테고리 분류 테스트
4. 연령대별 BMI 통계 계산 기능 테스트

이 4가지에 대해 먼저 실패하는 테스트 코드부터 작성해줘.
```

### [2] 최소 구현

```
위에서 작성한 테스트 코드가 통과할 수 있도록 최소한의 구현 코드를 작성해줘.
BMICalculator(또는 SHealth) 클래스를 만들어서 테스트를 통과시키는 데 집중해줘.
```

### [3] 클린코드 리팩토링

```
현재 작성된 Python 코드를 클린코드 원칙(SRP, DRY, 의미 있는 네이밍, 함수 분리 등)에 따라 리팩토링해줘.
특히 다음에 주의해줘:
- Magic Number 제거
- 한 함수의 책임 최소화
- 테스트하기 쉽도록 분리
```

### [4] 설계 다이어그램

```
현재 SHealth BMI 프로그램을 클래스 다이어그램 형태로 표현해줘.
- 주요 클래스, 책임, 메서드 포함
- 테스트 코드와 도메인 로직의 관계도 함께 보여줘
```

### [5] 테스트 커버리지 점검

```
현재 테스트 코드가 모든 분기 조건을 커버하고 있는지 점검해줘.
- 빠진 경계 조건이나 예외 상황이 있다면 테스트 케이스를 추가로 제안해줘.
```

### [준비-06] Cursor AI 프로젝트 규칙 파일 (`.cursorrules`) 작성

**프롬프트**
```
[P] 당신은 레거시 코드 작성/QA/리팩토링을 돕는 시니어 Python 엔지니어입니다.
[C] SHealth_BMI Python 프로젝트에서 Cursor AI가 항상 따라야 하는 규칙을
    프로젝트 루트의 .cursorrules 파일로 작성하려고 합니다.
[T] 아래 요구를 만족하는 .cursorrules 내용을 작성해줘.
    - 기술 스택: Python 3 + pytest + pytest-cov (+ coverage.py)
    - 절대 규칙 : 보안, 스타일, 의존성 관리 등 필수 준수사항 필요
    - 테스트 규칙 : pytest 기반, 커버리지 목표(라인 커버리지 90% 이상), skip 최소화, 신규 기능 테스트 필수
    - 리팩토링 규칙 : 기존 동작 보존, 중복 제거, 가독성 개선, dead code 제거, 테스트 통과 필수
    - Python 추가 규칙: 모든 함수/메서드에 type hint 작성 권장, 데이터 구조는 dataclass 활용 가능
    - 테스트 커버리지 목표: 라인 커버리지 90% 이상
[F] .cursorrules 파일을 생성해줘
```

**수행 내용**
- 프로젝트 루트에 `.cursorrules` 생성
- 기술 스택, 도메인 규칙(BMI 공식·분류·체중 0 보정), 절대 규칙(보안·PEP 8·의존성), Python 작성 규칙(type hint·dataclass·SRP), pytest·커버리지 90% 규칙, 리팩토링 원칙, 작업 체크리스트·금지 사항 반영
