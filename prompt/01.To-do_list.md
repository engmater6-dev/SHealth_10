## [01-01] 요구사항 분석 문서 작성

```
[P] 당신은 레거시 코드 작성/QA/리팩토링을 돕는 시니어 Python 엔지니어입니다.
[C] SHealth_BMI Python 프로젝트에서 README.md의 기능 요구사항을 기반으로
    Python 구현 관점에서 QA 분석 문서를 작성하려고 합니다.
[T] 아래 요구를 만족하는 requirements_analysis.md 내용을 작성해줘.
    1) 기능 요구사항 요약
       - 데이터 입력 및 전처리 (누락값 보정: weight=0, height=0)
       - BMI 계산 공식 및 분류 기준
       - 나이대별 통계 및 BMI 분포 계산
       - 전체 사용자 대비 BMI 범주 비율 계산
       - 정상 범위 사용자 목록 조회
       - 예외 처리 (잘못된 입력값 방어적 처리)
    2) Python 구현 시 주의점
       - 타입 힌트 작성 권장
       - dataclass 활용 가능
       - SRP에 따른 책임 분리
       - 로깅은 logging 모듈 사용, print 금지
       - PEP8 스타일 준수
    3) 코드 품질 개선 포인트 (코드 스멜, 리팩토링 관점)
       - 네이밍 개선
       - 하드코드 및 전역변수 제거
       - 함수 추출 및 중복 제거
       - dead code 및 불필요한 import 제거
       - 테스트 기반 리팩토링
    4) pytest 기준 테스트 시나리오 목록
       - 번호 매김, 입력/예상 출력/경계 조건 포함
       - BMI 계산 로직 TC
       - Age 평균치 보정 로직 TC
       - 정상/저체중/과체중/비만 분류 TC
       - Height=0 보정 TC
       - 전체 사용자 대비 BMI 분포 비율 TC
       - 예외 상황 TC
[F] Markdown 형식으로 작성하며, 표와 번호 목록을 포함한다.
    최종 결과는 doc 폴더를 생성하고 requirements_analysis.md 파일에 작성해줘
```
