| 관점 | SRP/OCP, Code Smell, Python 특화, PEP 8, 리팩토링 우선순위 1~5 |

**분석 대상 요약**

| 파일 | LOC | 핵심 이슈 |
|------|-----|-----------|
| `shealth.py` | 99 | `calculate_bmi`에 I/O·보정·계산·집계 집중 (SRP/OCP, Long Method) |
| `shealth_bmi.py` | 19 | 나이대·BMI 타입 코드 중복 하드코딩 (Duplicated Code, Magic Number) |

**문서 구성**

| 섹션 | 주요 내용 |
|------|-----------|
| §1 요약 | 파일별 LOC·핵심 이슈 |
| §2 SRP/OCP | `SHealth`, `calculate_bmi`, `main` 위반 근거 |
| §3 Code Smell | Long Method, Magic Number, Duplicated Code 등 10항 |
| §4 Python 특화 | 타입 힌트, Enum/dataclass/Protocol, encoding, print |
| §5 Pythonic 개선 | 전략 패턴, `__subclasshook__`, dataclass 스케치 |
| §6 우선순위 | 리팩토링 P1~5 |
| §7 종합 표 | 문제점 \| 원칙/스멜 \| 영향 \| 개선 \| 우선순위 (14행) |

**SRP 위반 (핵심)**

| 위치 | 위반 내용 |
|------|-----------|
| `SHealth` 클래스 | ETL + 통계 + 에러 출력 역할 혼재 |
| `calculate_bmi` | 파일 I/O, 상태 초기화, weight 보정, BMI, 비율 집계를 단일 메서드에서 처리 |
| `shealth_bmi.main` | 조립 + 콘솔 포맷 (진입점으로 일부 허용) |

**OCP 위반 (핵심)**

| 위치 | 위반 내용 |
|------|-----------|
| BMI `if/elif` (L79–86) | 임계값 18.5/23/25 고정, 범주 추가 시 메서드 수정 필요 |
| `range(20, 80, 10)` | `shealth.py` 2회 + `shealth_bmi.py` 1회 산재 |
| `row[1]`, `row[2]`, `row[3]` | CSV 스키마와 강결합 |
| `UNDERWEIGHT=100` 등 | IntEnum 대신 정수 코드만 사용 |

**확인된 버그·잠재 이슈**

| 이슈 | 현재 코드 | 권장 |
|------|-----------|------|
| BMI 25.0 비만 | `elif self.bmis[i] > 25` | `bmi >= 25` (README·QA와 정합) |
| 빈 행 처리 | `if not row: break` | `continue` 또는 검증 후 스킵 |
| height=0 보정 | 미구현 | `impute_heights` 단계 추가 (요구 §4.1) |
| 파일 없음 | `print` 후 `return 0` | `logging` 또는 예외 전파 |

**리팩토링 우선순위 (분석 문서 §6)**

| 순위 | 항목 | 이유 |
|:---:|------|------|
| **1** | `calculate_bmi` 4단계 분해 | SRP·테스트·커버리지 90% 전제 |
| **2** | Magic Number → 상수/Enum | OCP·경계값 버그 방지 |
| **3** | `HealthRecord` + 나이대 그룹핑 통합 | 중복 제거·height 보정 용이 |
| **4** | `shealth_bmi.py` 상수·argparse·포맷터 | 진입점·도메인 정렬 |
| **5** | Protocol/전략 패턴 | 확장성 (1~4 이후) |
