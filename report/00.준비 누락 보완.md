### 3.2 [보완-02] [준비-08] 실행

#### `requirements-dev.txt` (신규)

```
pytest>=8.0,<9
pytest-cov>=4.0,<5
```

- 프로덕션 런타임 의존성 없음 (dev 전용)

#### `README.md` 「실행 환경」 갱신

| 구분 | Before | After |
|------|--------|-------|
| 설치 | `pip install pytest` | `pip install -r requirements-dev.txt` |
| 테스트 | `test_shealth_bmi.py` 단일 파일 | `src/test/python` 디렉터리 |
| 커버리지 | 없음 | `.cursorrules`와 동일한 `--cov-fail-under=90` 블록 추가 |
| To-Do §0 | `[ ]` 2건 | `[x]` 2건 |

**커버리지 명령 (`.cursorrules`와 동일)**

```bash
python -m pytest src/test/python --cov=src/main/python --cov-report=term-missing --cov-fail-under=90
```

#### 기타 반영

- 프로젝트 구조 트리에 `requirements-dev.txt` 추가
- `prompt/00.준비.md` — [준비-08] 섹션
- `report/00.report.md` — 준비-08·체크리스트·한계 문구 갱신

| 명령 | 결과 |
|------|------|
| `pip install -r requirements-dev.txt` | 설치 성공 |
