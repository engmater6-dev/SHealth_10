## 4. 구현 상세

### 4.1 비교 대상

| 항목 | 값 |
|------|-----|
| 진입점 | `shealth_bmi.main()` |
| 입력 | 프로젝트 루트 `shealth.dat` |
| 출력 | stdout **6줄** (나이대 20~70, 소수 6자리) |
| 제외 | stderr(INFO 로그 등) |

### 4.2 `texttest_fixture.py` API

| 함수 | 역할 |
|------|------|
| `capture_cli_stdout(path, use_subprocess=False)` | CLI stdout 캡처 |
| `normalize_output(text)` | CRLF→LF, 줄 끝 공백 제거 |
| `read_golden` / `write_golden` | 기준 파일 I/O |
| `approve_output(actual, golden_path)` | 비교 또는 `UPDATE_GOLDEN=1` 갱신 |
| `golden_dir()` | `src/test/golden` |

### 4.3 Golden 테스트 케이스

| 테스트 | 내용 |
|--------|------|
| `test_golden_master_shealth_dat_stdout` | `shealth.dat` actual vs `shealth_dat_stdout.txt` |
| `test_golden_master_subprocess_matches_inprocess` | subprocess·in-process 캡처 일치 검증 |

실패 시 `difflib.unified_diff`로 expected/actual diff를 `pytest.fail` 메시지에 포함합니다.

### 4.4 기준 출력 샘플 (요약)

```text
20 - underweight = 3.511053, normal = 23.797139, overweight = 11.833550, obesity = 60.858257
… (30·40·50·60대) …
70 - underweight = 0.529101, normal = 12.345679, overweight = 10.758377, obesity = 76.366843
```

전문은 `src/test/golden/shealth_dat_stdout.txt` 참조.

## 5. 실행·갱신 명령

```bash
# 기본 (golden 제외, 47건)
python -m pytest -v

# Golden Master만 (2건)
python -m pytest -m golden_master -v

# 기준 파일 갱신 (의도적 통계 변경 후)
set UPDATE_GOLDEN=1
python -m pytest -m golden_master -v

# 전체 (49건)
python -m pytest -m "" -v
```
