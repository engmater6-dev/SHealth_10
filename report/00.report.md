## 3. `.cursorrules` 주요 내용

프로젝트 루트 `.cursorrules`에 정의된 핵심 규칙 요약입니다.

### 3.1 기술 스택

- Python 3.8+
- pytest, pytest-cov, coverage.py
- 표준 라이브러리 우선 (`csv`, `dataclasses`, `typing` 등)

### 3.2 절대 규칙

- **보안:** 비밀 정보·경로 조작·`eval`/`exec` 등 금지, 입력 검증
- **스타일:** PEP 8, 매직 넘버 상수화, 전역 가변 상태 금지
- **의존성:** 최소화, `requirements.txt` 버전 명시, dev/prod 분리
- **변경 범위:** 요청 범위 외 대규모 변경·무단 커밋/푸시 금지

### 3.3 테스트·품질 목표

| 항목 | 목표 |
|------|------|
| 테스트 프레임워크 | pytest (신규), unittest는 점진 이전 |
| 라인 커버리지 | **90% 이상** (`--cov-fail-under=90`) |
| skip 사용 | 최소화, 사유 주석 필수 |
| 신규 기능 | 반드시 테스트 추가 |

**권장 커버리지 명령**
```bash
python -m pytest src/test/python --cov=src/main/python --cov-report=term-missing --cov-fail-under=90
```

### 3.4 Python·리팩토링

- 모든 함수·메서드 **type hint** 필수
- 구조화 데이터는 **dataclass** 우선
- 리팩토링 시 **동작 보존**, 중복 제거, dead code 제거, 테스트 통과 필수

### 3.5 도메인 규칙 (변경 시 필수 확인)

- BMI = kg / m²
- 분류: ≤18.5 / 18.5~23 / 23~25 / ≥25
- `weight = 0` → 동일 나이대(10년 단위) 평균 보정
- 나이대별 BMI 범주 **비율(%)** 통계
