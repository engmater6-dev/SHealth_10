## 1. 기능 요구사항 요약

### 1.1 시스템 개요

| 항목 | 내용 |
|------|------|
| 목적 | 삼성 헬스 수집 데이터로 **나이대별** BMI 범주(저체중/정상/과체중/비만) **비율(%)** 통계 산출 |
| 입력 파일 | CSV 형식 `shealth.dat` (헤더: `id,age,weight,height`) |
| 단위 | 체중 kg, 키 cm, BMI 무차원 |
| 출력 | CLI 통계 출력, API 형태의 조회 메서드(목표 설계) |

### 1.2 데이터 입력 및 전처리

#### 1.2.1 입력 스키마

| 필드 | 타입 | 설명 | 제약 |
|------|------|------|------|
| `id` | 정수/문자열 | 사용자 식별자 | 중복 허용 여부는 명시 없음 — 동일 ID 다건 시 목록 조회 정책 정의 필요 |
| `age` | 정수 | 만 나이 또는 수집 나이 | 나이대 구간 매핑에 사용 |
| `weight` | 실수 | 체중(kg) | `0` = 누락(보정 대상) |
| `height` | 실수 | 키(cm) | `0` = 누락(보정 대상, **기능 개선 항목**) |

#### 1.2.2 파일 읽기

1. CSV 첫 행은 헤더이며 스킵한다.
2. 데이터 행은 `id, age, weight, height` 순으로 파싱한다.
3. 빈 행·잘못된 컬럼 수·비숫자 값에 대한 **방어적 처리**가 필요하다 (현재 구현은 예외 전파 가능).
4. 파일이 없으면 오류를 기록하고 처리 건수 `0`을 반환한다 (현재: `print` 사용 → `logging`으로 전환 권장).

#### 1.2.3 누락값 보정 규칙

| 누락 조건 | 보정 방법 | 나이대 정의 |
|-----------|-----------|-------------|
| `weight == 0` | 동일 **나이대** 내 `weight > 0` 레코드의 **평균 체중**으로 대체 | 10년 단위: 20≤age&lt;30 → 20대, …, 70≤age&lt;80 → 70대 |
| `height == 0` | 동일 **나이대** 내 `height > 0` 레코드의 **평균 키**로 대체 | weight와 동일 (README Activities 4단계 **신규 요구**) |

**보정 순서 (권장):**

1. 파일 로드 → 원시 레코드 리스트 구성  
2. 나이대별 `weight` 평균 계산 → `weight=0` 보정  
3. 나이대별 `height` 평균 계산 → `height=0` 보정  
4. BMI 계산 및 통계 집계  

**경계·예외:**

- 해당 나이대에 보정용 유효 샘플이 **0건**이면: 전체 평균 fallback 여부를 명세에 정의하거나, 해당 레코드를 통계에서 제외하고 로그 경고.
- 보정 후에도 `height=0`이면 BMI 계산 시 **ZeroDivisionError** — 반드시 사전 차단.

### 1.3 BMI 계산 공식 및 분류 기준

#### 1.3.1 계산 공식

```
BMI = weight(kg) / (height(m))²
height(m) = height(cm) / 100
```

#### 1.3.2 분류 기준 (README 확정)

| 범주 | 조건 (수학) | 조건 (구현 권장) |
|------|-------------|------------------|
| 저체중 | BMI ≤ 18.5 | `bmi <= 18.5` |
| 정상체중 | 18.5 &lt; BMI &lt; 23 | `18.5 < bmi < 23` |
| 과체중 | 23 ≤ BMI &lt; 25 | `23 <= bmi < 25` |
| 비만 | BMI ≥ 25 | `bmi >= 25` |

#### 1.3.3 경계값 정합성 (QA 주의)

| BMI 값 | 기대 범주 | 비고 |
|--------|-----------|------|
| 18.5 | 저체중 | 상한 포함 |
| 18.500001 | 정상 | |
| 23.0 | 과체중 | 하한 포함 |
| 25.0 | 비만 | README "25 이상" — **현재 코드는 `> 25`만 비만 처리하여 25.0 누락 버그 가능** |

### 1.4 나이대별 통계 및 BMI 분포 계산

#### 1.4.1 나이대 구간

- 구간: `[20,30)`, `[30,40)`, …, `[70,80)` — `range(20, 80, 10)`과 동일.
- 20 미만·80 이상 사용자: README 미명시 → **통계 제외** 또는 **별도 구간** 정책을 문서·테스트에 고정.

#### 1.4.2 나이대별 BMI 분포 비율

특정 나이대 `A`에 속한 사용자 `N`명에 대해:

```
비율(범주) = (해당 범주 인원 수 / N) × 100   [%]
```

| 출력 키 (현재) | 의미 |
|----------------|------|
| `(age_class, 100)` | 저체중 비율 |
| `(age_class, 200)` | 정상 비율 |
| `(age_class, 300)` | 과체중 비율 |
| `(age_class, 400)` | 비만 비율 |

**검증 규칙:** 동일 나이대 4개 비율 합 ≈ 100% (반올림 오차 허용 범위 정의, 예: ±0.01).

#### 1.4.3 특정 연령대 BMI 분포 (Activities 4)

- `get_bmi_ratio(age_class, bmi_type)` 형태로 **특정 연령대** 조회 (현재 부분 구현).
- 상수 `100/200/300/400` 대신 `Enum`·의미 있는 이름 권장.

### 1.5 전체 사용자 대비 BMI 범주 비율 계산 (신규)

| 항목 | 설명 |

### 1.6 정상 범위 사용자 목록 조회 (신규)

| 항목 | 설명 |
|------|------|
| 조건 | `18.5 < BMI < 23` |

### 1.7 예외 처리 (방어적 처리)

| 상황 | 기대 동작 |

## 2. Python 구현 시 주의점

### 2.1 타입 힌트

- **모든 공개 함수·메서드**에 인자·반환 타입 명시 (`str`, `int`, `float`, `list[UserRecord]` 등).
- Python 3.8 호환 시 `from __future__ import annotations` 또는 `typing.List`, `Dict`, `Optional` 사용.

```python
def classify_bmi(bmi: float) -> BmiCategory: ...
def load_records(path: str) -> list[UserRecord]: ...
```

### 2.2 dataclass 활용

| 용도 | 예시 |
|------|------|
| 단일 사용자 레코드 | `@dataclass UserRecord: id, age, weight, height` |
| 통계 결과 | `@dataclass AgeGroupStats: age_class, counts, ratios` |
| 설정/상수 묶음 | `@dataclass BmiThresholds` (18.5, 23.0, 25.0) |

- 가변 전역 리스트(`self.ages`, `self.weights` …) 대신 **`list[UserRecord]`** 로 상태를 명확히 한다.

### 2.3 SRP에 따른 책임 분리 (권장 모듈/클래스)
