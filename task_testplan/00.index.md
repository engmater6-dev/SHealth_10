## 공통 제약 (모든 Phase)

- **Python 3.8+**, `pytest`, `pytest-cov` (`requirements-dev.txt`)
- `@pytest.mark.skip` **사용 금지** (미구현은 테스트 추가하지 않거나 Phase를 Activities 4로 이관)
- 신규 TC는 **`tmp_path` CSV fixture** 우선 — `shealth.dat`는 스모크·회귀(#31, #44)에만
- 공개 API 유지: `calculate_bmi(path) -> int`, `get_bmi_ratio(age, 100|200|300|400) -> float`
- 도메인 계층 `print` 금지 — 예외·스킵은 `logging` + `caplog` 검증
- `.cursorrules`: 라인 커버리지 **≥ 90%**
