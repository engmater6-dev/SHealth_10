    - 보정 순서: `_impute_weights()` **다음** `_impute_heights()` **다음** `_compute_bmis()`

[T] `_impute_heights()`를 구현하고 파이프라인에 연결해줘.
    1) `_impute_weights` 구조 미러링
       - `AGE_BANDS` 순회 → `_records_in_band` → `height > 0` 유효 샘플 평균
       - `record.height == 0.0` 인 레코드에 평균 적용
    2) `calculate_bmi` 본문
       ```python
       self._impute_weights()
       self._impute_heights()
       self._compute_bmis()
       ```

    4) weight·height 동시 0 (TC #24) — weight 먼저 보정 후 height 보정으로 BMI 산출 가능한지 검증
