## 프롬프트

```
@README.md @doc/requirements_analysis.md @doc/feature_policy.md
@src/main/python/shealth.py
@src/test/python/test_load_records.py @src/test/python/conftest.py

[P] 방어적 프로그래밍·로깅에 집중하는 Python 개발자입니다.

[C] 제약
    - 빈 행: 기존 `_is_blank_row` + `continue` **유지**
    - 파일 없음: 기존 `FileNotFoundError` → `logger.error` **유지**
    - 정책(Phase 01): 잘못된 행 → **스킵 + `logger.warning`** (전체 실패 금지 unless 정책 변경)
    - 유효 행만 `self.count` 증가 — 스킵 행은 count 제외
    - `DictReader` + `FIELD_*` 상수 유지

[T] `_load_records`에 방어적 행 처리를 추가해줘.
    1) **컬럼 부족** — 필수 키 `id,age,weight,height` 누락 또는 빈 값 → warning + continue (TC #39)
    2) **비숫자** — `int`/`float` 변환 실패 → warning + continue (TC #38)
       - `ValueError`, `KeyError` 등 행 단위 catch (너무 넓은 `except Exception` 지양)
    3) 로그 메시지에 **행 번호 또는 raw row 요약** 포함 (디버깅용, PII 최소)
    4) 헤더만·정상 N행 — 기존 TC #37, #43 **회귀 없음**

[F]
