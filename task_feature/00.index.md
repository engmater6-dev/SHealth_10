## 공통 제약 (모든 Phase)

- **Python 3.8+**, pytest, pytest-cov (`.cursorrules`)
- **공개 API 하위 호환:** `calculate_bmi(filename) -> int`, `get_bmi_ratio(age_class, bmi_type) -> float` 유지
- 신규 API는 **type hint** + docstring — `BmiCategory` / `list[int]` 등 명시
- 보정 순서: **load → impute weight → impute height → compute BMI → aggregate** ([`requirements_analysis.md`](../doc/requirements_analysis.md) §1.2.3)
- 도메인 `print` 금지 — 스킵·보정 불가는 `logging.warning` + `caplog` 검증
- `@pytest.mark.skip` **사용 금지**
- Golden Master: `shealth.dat` 통계 변경 시 `UPDATE_GOLDEN=1` 절차만 허용 ([`task_golden_master/`](../task_golden_master/00.index.md))
- 라인 커버리지 **≥ 90%** 유지
